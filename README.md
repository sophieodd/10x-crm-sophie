# 10X CRM

## About

10X CRM is my JavaScript exam project. It is a small browser-based CRM for tracking clients and sales activity. The current version supports account creation and login.

## Features

- Sign up with inline validation and duplicate email checks.
- Log in with a registered account.
- Save accounts and the login session in browser storage.

## Tech Stack

HTML, CSS, vanilla JavaScript and localStorage.

## How to Run

1. Clone the repository or download the project.
2. Open the folder in VS Code.
3. Serve the folder with Live Server and open `index.html`.
