# 10X CRM

## About

10X CRM is my vanilla JavaScript exam project. 10X CRM is the back office for my CTRL+ME shop concept. It tracks client relationships, sales opportunities and deal stages.

## Features

- Create a test account and log in with form validation.
- View client totals, active deals, won revenue and recent clients on the dashboard.
- Load sample clients from DummyJSON.
- Add, edit and delete clients. Deleting a client asks for confirmation.
- Change a client’s deal stage using the colored status dropdown.
- Upload an optional company logo when adding or editing a client.
- Switch between light and dark mode. The theme and client changes survive a refresh.

Accounts, sessions and client changes are stored in the current browser.

## Tech Stack

HTML, CSS, vanilla JavaScript, Fetch API, DummyJSON and localStorage.

## How to Run

1. Clone the repository or download it.
2. Open the project folder in VS Code.
3. Start Live Server and open `index.html`.
